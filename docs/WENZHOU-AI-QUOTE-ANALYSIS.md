# 温州项目报价表：AI 部分分析

数据来源：`温州项目-报价表-5622人日.xlsx`（2026-11-07 版）。
口径：开发建设按 1,000 元/人日；金额 = 人日 × 1,000。AI 相关条目按描述中明确出现 AI / 智能体 / 大模型 / 知识库 / 智能推荐 / 识别等语义筛选，排除仅“自动生成单据”的规则型功能。

## 0. 一句话结论

AI 不是报价表里的一个小附件，而是**约占开发建设 1/3 人日、首年约 230 万元**的主盘。其中核心「AI 智能工作台」1,293 人日 / 129.3 万元，嵌入式 AI 572 人日 / 57.2 万元，Token 15 万元/首年，AI 相关外部数据约 28 万元/年。

能力中心能承接的是**底座**（模型网关、技能目录、积分、审计、MCP、任务基础），大约覆盖 AI 总人日的 15%–25%；**20 个场景工作流、知识库/RAG、AI 应用前端、数据接入和嵌入式 AI 才是工作量主体**，不能按“已有平台直接复用”估。

## 3. 能力中心能接多少

### 3.1 直接映射

| 报价模块 | 能力中心现状 | 差距 | 判断 |
|---|---|---|---|
| 模型配置（文本/生图/视频） | 有文本模型配置、SSE 网关、超时/备用模型 | 无生图/视频适配、无多模态路由、无统一限额 | **部分复用，需扩** |
| 模型审计日志 | 有 `model_call_logs`、审计事件 | 无按任务/专家的 Token/积分/耗时看板 | **部分复用** |
| 智能体管理（Skill/专家/资源组合） | 有助手、提示词、技能绑定、工具目录 | 无任务型专家、无资源组合可视化、无 Skill 版本/权限 | **部分复用** |
| Skill 市场 | 有 323 个能力目录、搜索/详情/收藏、按能力专属表单 | 无“安装/启停/版本/权限”，目录是平台内置而非市场 | **部分复用** |
| MCP 连接器 | 有对外 MCP Server；刚接入平台级 MCP Client（商标） | 无用户自定义 MCP、OAuth 授权 UI、连通性检测、工具启停 | **部分复用** |
| 积分/套餐 | 有钱包、预留-捕获、流水、账单 | 无套餐 SKU、购买/续费/权益同步、积分包 | **部分复用** |
| 任务中心/自动化 | 有会话、BullMQ 异步任务 | 无统一任务入口、意图路由、定时/事件触发 | **部分复用** |
| 知识库/RAG | 无 | 向量库、分段、检索、权限全缺 | **新建** |
| AI 应用中心（商品库/CRM/店铺/营销） | 有店铺账号、文件、调用记录 | 无商品库、CRM、营销素材库、AI 应用入口 | **新建** |
| 20 个场景工作流 | 有工具调用 + 计费 + 记录 | 无多步编排、数据接入、领域提示词、输出模板 | **新建** |
| 嵌入式 AI（商城/SCM/外综服/数据中台） | 无对应业务系统 | 需要与各业务系统集成 | **新建** |

### 3.2 可复用比例（粗略）

- **高复用底座**：模型配置/调用、积分、审计、Skill/MCP、任务基础，约 **250–350 人日** 等价工作量。
- **部分复用**：专家中心（提示词/工具绑定）、AI 应用中心（店铺/文件）、任务/自动化，约 **150–250 人日** 的模式可借鉴。
- **必须新建**：20 个场景工作流、知识库/RAG、7 类外部数据接入、AI 应用前端、6 个平台的嵌入式 AI，约 **1,300–1,450 人日**。

也就是说：**能力中心能覆盖 AI 总人日的 15%–25%，不是 50%。** 现有代码最大的价值是“不用从零搭账号、目录、计费、模型网关、审计和 MCP”，而不是“AI 工作台已经做完了”。

## 4. 主要风险

### 4.1 商务/成本

1. **Token 预算可能不够**：2.41 元/次覆盖生图/识图/视频，视频是最大变量；150k 是首年费用包，不是封顶，超量谁承担没写。
2. **AI 人日单价 1,000 元偏低**：如果真要配算法/大模型工程师，这个 blended rate 会压毛利；用现有团队+能力中心复用才成立。
3. **外部数据 620k 是 pass-through**：数据许可是否允许 AI 加工、衍生、再分发，需要合同确认；否则功能做了也不能用。
4. **第二年 OPEX 未报价**：Token、数据订阅、云资源、维保都要续费，首年 150k 不是长期成本。
5. **509 条固定范围 + AI 条目描述模糊**：没有验收指标（准确率、时延、单任务成本），容易陷入无限调优。

### 4.2 技术/数据

1. **知识库/RAG 是外综服合规 Agent 和 AI 客服的地基**，能力中心没有向量库；这是新增基础设施，不是一个小功能。
2. **7 类外部数据格式/授权/频率差异大**：海关、采购商、合规、渠道、物流、税局、银行；需要连接器框架 + 缓存 + 重试 + 数据质量监控。
3. **多模态模型**：文本、生图、视频、图片理解、OCR 的供应商、限额、失败降级都不同；现有模型网关只覆盖文本 chat。
4. **任务型专家 ≠ 聊天助手**：需要任务输入、参数、执行、产物、重跑、审计；现有 chat SSE + 工具循环只是其中一种交互。
5. **长任务/异步**：20 个场景里很多是分钟级（报告、生图、视频），不能都走同步 HTTP；需要任务中心 + 通知。
6. **多租户/企业隔离**：温州平台可能服务多家企业，积分、知识库、数据、模型配额都要按企业隔离；现有 schema 有 tenant 但只跑过单租户。
7. **前端工作量大**：AI 应用中心、专家中心、任务中心、Skill 市场、配置后台都是新 UI；能力中心只有目录/聊天/管理端。

### 4.3 合规/交付

1. **等保三级 + 密评**：第三方费用里只有测评费（30k + 40k），整改工作量未计；AI 涉及用户数据、支付、报关，整改不会小。
2. **AIGC 内容标识/审核**：生成内容需要标识、留痕、可追溯；现有只有 `CONTENT_BLOCKED` 关键字拦截。
3. **个人信息/跨境数据**：采购商联系人、询盘、邮件涉及个人信息和跨境传输，需要 PIPL/数据出境评估。
4. **模型供应商合规**：报价没指定模型厂商；境内项目可能要求备案/国产化/数据不出境。
5. **验收标准缺失**：AI 条目没有准确率、召回、时延、成本、人工替代率等指标，验收容易扯皮。
6. **没有训练/微调预算**：150k Token + 模型配置都是“调用现成模型”，没有数据标注、微调、评测集建设费用；如果验收要求行业模型微调，需要另计。
7. **知识库 14 人日只是管理界面**：不含向量库、切片、embedding、召回评估、权限和更新链路；实际 RAG 底座通常要 40–80 人日。
8. **MCP 连接器 22 人日偏紧**：用户自定义 MCP + OAuth 授权 + 连通性检测 + 工具启停，做到生产可用不止 22 人日；我们刚做的平台级单账号版只能算最小验证。

## 5. 建议打法

### 5.1 定位

把能力中心定位成 **“AI 能力底座”**，不是“AI 工作台成品”：

- 底座：身份、目录、技能、MCP、模型网关、积分、审计、文件、任务队列。
- 温州项目层：专家、场景工作流、知识库、AI 应用、数据接入、门户/多语言。

这样既能复用，又不会把温州特有的业务硬塞进白标平台。

### 5.2 分期

**Phase 1（建议 3 个月，先做能验收的闭环）**

- AI 能力配置后台：模型配置（文本+生图）、Skill/专家配置、模型审计、积分明细（复用+扩展现有能力中心）。
- 专家中心：先做 3 个——商品专家、合规专家、获客专家（约 44+37+26 = 107 人日）。
- 场景工作流：先做 5 个高频——选品决策（24）、AI 产品描述（28）、商品图/场景图（31）、竞品洞察（28）、全球海关数据获客（28），合计约 139 人日。
- 任务中心 MVP + 异步任务 + 通知。
- 1 个 AI 应用：AI 商品库。
- Token 按场景设硬上限 + 超量告警。

**Phase 2（3–6 个月）**

- 剩余专家（总控、数据洞察、行研、营销、定制）。
- 剩余 15 个场景工作流。
- 知识库/RAG（先合规、商品、客服三个库）。
- 自动化（定时 + 事件触发）、套餐/积分包。
- AI 应用：CRM、全球店铺中心、智能营销中心。

**Phase 3（6–9 个月）**

- 嵌入式 AI：商城智能搜索/询价、SCM 评级/预警/补货、外综服合规 Agent、数据中台报告/清洗、服务市场 AI 助手。
- 多语言/门户/IM 集成。
- 等保/密评整改、AIGC 合规、数据出境评估。

### 5.3 范围与报价建议

1. **Token 改成“基础包 + 超量单价”**，按场景设月度上限；视频单独计价或单独限额。
2. **外部数据合同先签**，明确 AI 加工/衍生/再分发权利；否则相关场景不上线。
3. **AI 条目补验收指标**：每个工作流定义输入、输出、准确率/人工复核率、P95 时延、单次成本。
4. **云资源/向量库/存储单列**，不要含在 1,000 元/人日里。
5. **复用能力中心的部分单独标注**，把节省的人日转成质量/测试/数据治理，而不是直接降价。
6. **先做 5 个场景的样板**，用温州真实数据跑通，再批量复制；不要 20 个同时开工。

## 7. 与刚接入的商标能力的关系

报价表里有两处和商标直接相关：

- 外综服「合规专家 → 知识产权与外汇税务检查」15 人日；
- 项目总价里的「海外商标知识产权注册」314,000 元（服务费，不是软件）。

我们刚接入的近似商标检索、美国商标详情、尼斯分类查询，正好可以支撑合规专家的知识产权初筛，也能给商标注册服务导流。但当前是平台级单账号、额度已耗尽，正式用到温州项目前需要先解决：上游配额、每用户 OAuth、白标授权条款。
