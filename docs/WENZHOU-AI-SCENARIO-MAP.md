# 温州项目 AI：场景 / 能力 / 功能地图

分支：`feature/wenzhou-ai-workbench`
定位：**能力中心是 AI 能力底座，温州项目是长在上面的业务层。** 不另起一套账号、目录、计费或模型网关。

---

## 0. 先统一几个词

| 词 | 含义 | 在能力中心里的落点 |
|---|---|---|
| 能力 / Capability | 一个可调用的工具：输入 schema、输出、价格、调用记录 | `tools` + `InvokeService` |
| 专家 / Expert | 有角色提示词、可用能力、知识库、模型和输出契约的作业单元 | `agents` 扩展为任务型专家 |
| 场景 / Scenario | 一个有名字的多步作业：输入、步骤、数据依赖、输出模板、验收 | 新增 `scenario_defs` + `scenario_runs` |
| 任务 / Task | 一次场景运行：输入、状态、产物、耗时、积分、审计 | 复用 BullMQ + 新增任务中心 |
| AI 应用 / App | 有持久数据的业务界面：商品库、CRM、营销素材、店铺中心 | 新增 app 模块 |
| 技能 / Skill | 可被专家调用的能力包，可安装/启停/配权限 | 现有目录 + Skill 市场扩展 |

**原则：能力只做一次，专家和场景只做编排。** 不允许在场景里再写一套上游调用、计费或鉴权。

---

## 1. 场景总览

报价表 AI 工作台包含：

- **8 类专家**：总控、商品、获客、合规、数据洞察、行研、营销、其他定制。
- **21 个场景工作流**：选品、商品内容、视觉、获客、营销、分析、报价等。
- **4 个 AI 应用**：AI 商品库、智慧 CRM、全球店铺中心、智能营销中心。
- **8 项平台能力**：模型配置、模型审计、智能体管理、知识库、任务中心、自动化、Skill 市场/MCP、套餐订阅。
- **6 个平台的嵌入式 AI**：门户、B2B 商城、服务市场、外综服、SCM、数据中台。

## 3. 8 类专家

| 专家 | 职责 | 主要调用 | 现有基础 | 需要补 |
|---|---|---|---|---|
| 总控专家 | 理解需求、推荐专家、引导发起任务 | 全部专家 | 会话、助手 | 意图路由、专家推荐、任务编排 |
| 商品专家 | 商品采集/分析、标题卖点、多语言描述、商品图 | 场景 2、3、8 | 12 个助手、Listing 工具 | 商品库、生图、任务型输出 |
| 获客专家 | 海关/采购商数据、市场筛选、潜客、触达 | 场景 12–15 | 工具目录、CRM（新增） | 数据连接器、画像、邮件 |
| 合规专家 | 准入、关税、认证、知识产权、外汇税务、单证风险 | 场景 4 + 商标 | `compliance-check`、商标 3 能力 | 合规知识库、规则库 |
| 数据洞察专家 | 商品/店铺/客户/询盘/订单指标、异常、趋势 | 场景 7 | 店铺、调用记录 | 数据接入、指标模型 |
| 行研专家 | 行业/市场/政策/海关/社媒/竞品研究 | 场景 11 | 无 | 数据接入、报告生成 |
| 营销推广专家 | 多语言营销内容、投放建议 | 场景 9、10 | 文案/翻译工具 | 生图/视频、素材库 |
| 其他定制专家 | 按项目配置专属专家 | 任意 | 助手配置 | 专家配置 UI、资源组合 |

**专家不是新的一堆 prompt 文件。** 专家 = 现有 agent + 任务型输入/输出契约 + 可用能力/知识库/模型 + 权限。能复用 `agents`、`agent_tools`、`ai_models` 就不要新建表。

## 5. 8 项平台能力

| 能力 | 报价表要求 | 现有 | 整合方式 |
|---|---|---|---|
| 模型配置 | 文本/生图/视频模型，供应商、上下文、限额、测试、启停、默认 | `ai_models`、`ModelService` | 加 `modality`，扩图片/视频适配，不新建模型表 |
| 模型审计 | 时间、用户、任务、Token/积分、耗时、状态、异常、检索 | `model_call_logs`、`audit_events` | 加任务 ID/专家 ID/积分字段，做审计页 |
| 智能体管理 | Skill 信息/发布/权限；专家定义；模型+知识库+Skill+MCP+可见范围 | `agents`、`agent_tools`、`tools` | 扩专家配置，不另建 agent 体系 |
| 知识库 | 创建、导入、分段索引、权限、更新 | 无 | 新增 `knowledge_*` + 向量检索 |
| 任务中心 | 自然语言/图片/商品/店铺发起，选专家、补参数、执行 | 会话、`AsyncTask` | 新增任务对象和任务页，复用队列 |
| 自动化 | 定时/业务事件触发，启停/立即运行/记录 | BullMQ | 加调度与事件规则 |
| Skill 市场 / MCP | Skill 展示/搜索/启停；MCP 授权、连通性、工具管理 | 能力目录、`McpService` | 目录加“市场”视图；MCP 加每用户授权/工具启停 |
| 套餐订阅 | 套餐、积分、购买/续费/升级/退款、权益同步 | 钱包、流水 | 加 `subscription_plans`/`entitlements`，不另建钱包 |

## 6. 嵌入式 AI（第二阶段以后）

| 平台 | 嵌入式 AI | 整合方式 |
|---|---|---|
| 平台门户 | 智能客服 IM、智能入驻引导 | 复用会话 + 新增 IM/入驻知识库 |
| B2B 商城 | 智能搜索、AI 询价、商品提效、采集、信用证/报关单识别 | 调用能力中心工具 + 商城业务对象 |
| 服务市场 | AI 助手、服务商推荐、物流报价 | 场景 + 服务商数据 |
| 外综服 | 合规 Agent、境内/境外知识库、合规诊断 | 合规专家 + 知识库 |
| 供应链 SCM | 供应商评级、订单分发、履约预警、补货、智能入库 | 场景 + SCM 数据 |
| 数据中台 | 风险预警、月报/季报、数据清洗、分类打标 | 数据中台任务调用模型能力 |

这些不要在能力中心里重写业务系统；用 API/事件把 AI 能力嵌进去。

### 7.3 数据模型（additive）

- `expert_defs`：key、名称、角色、输入/输出 schema、模型、可见范围；或直接扩 `agents`（优先扩，避免两套）。
- `scenario_defs`、`scenario_steps`：场景、步骤顺序、工具/专家引用、输出模板。
- `scenario_runs`：输入、状态、进度、产物、积分、错误、任务 ID。
- `knowledge_bases`、`knowledge_documents`、`knowledge_chunks`：知识库、文档、分段、向量。
- `ai_products`、`crm_customers`、`crm_contacts`、`marketing_assets`：AI 应用数据。
- `automation_rules`、`automation_runs`：定时/事件。
- `subscription_plans`、`subscriptions`、`entitlements`：套餐与权益。
- `task_artifacts`：任务产物与文件关联。

所有表继续带 `tenant_id`，按企业隔离；迁移只加表/加列，不改现有字段语义。

### 7.4 不要做

- 不新建第二套用户/登录。
- 不新建第二套钱包/流水。
- 不在场景里直连上游供应商；一律走 `InvokeService` / `McpService`。
- 不为每个场景写一套工具调用和计费。
- 不做通用表单搭建器；能力表单仍然一能力一个组件。
- 不把温州品牌写进能力中心核心；用主题/配置。

## 8. 第一批 vertical slice

### 8.1 选品专家（P0，先跑通“专家 → 场景 → 任务 → 计费 → 审计”）

流程：

```
输入：关键词、站点、成本/售价、类目
  ↓
选品简报（product-picker）
  ↓
竞品洞察（competitor-insight，可选）
  ↓
利润测算（profit-estimator）
  ↓
季节日历（season-calendar）
  ↓
合规初筛（compliance-check + 商标，可选）
  ↓
输出：选品报告 + 调用记录 + 积分流水
  ↓
保存为任务 / 可加入 AI 商品库
```

新增：`scenario_defs`（选品）、`scenario_runs`、任务页、报告模板。
复用：4–5 个现有工具、`InvokeService`、`WalletService`、`AgentService`、审计。
验收：一次任务能看到步骤、每步调用、总积分、报告、失败重试；不新增任何上游直连代码。

### 8.2 合规专家（P0/P1）

- 复用：`compliance-check` + 商标 3 能力。
- 新增：合规知识库（准入/认证/关税）、报告模板。
- 前置：商标上游额度、每用户 OAuth。

### 8.3 商品专家（P1）

- 复用：`listing-copy`、`title-optimizer`、`translate-listing`、`main-image-brief`。
- 新增：AI 商品库、生图模型、素材库。

## 9. 建议排期

| 阶段 | 目标 | 主要交付 |
|---|---|---|

## 10. 待确认
